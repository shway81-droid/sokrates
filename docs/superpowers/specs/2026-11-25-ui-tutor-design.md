# 화면 디자인 바꾸기: 2번 "차분한 튜터" (설계)

2026-11-25 · 배포 전 UI 점검에서 사용자님이 다섯 후보 가운데 2번(칸 아카데미 칸미고처럼 차분한 대화 말풍선)을 골랐습니다.

## 왜
- 배포 전에 세 방법(엘렌코스·모르는 친구·오답 탐정)의 화면을 한 모양으로 다듬습니다.
- 문답이 "질문 카드 + 회색 기록 줄"로 떨어져 있어 대화 흐름이 잘 보이지 않았습니다. 말풍선이 쌓이면 흐름이 한눈에 보입니다.
- 위 막대가 1280px에서도 "처음으로"·"설정" 글자가 두 줄로 꺾였습니다.

## 바꾸는 것 (사용자님이 승인한 목록)
| 부분 | 바꾼 뒤 |
|---|---|
| 색 | 옅은 회색 바탕, 흰 카드, 파란 강조(#1865F2 계열) |
| 글꼴 | 모두 본문 글꼴(Noto Sans KR), 질문만 굵게. 고운돋움은 쓰지 않음 |
| 문답 | 말풍선 대화: AI 왼쪽(동그라미 그림 + 흰 말풍선), 학생 답 오른쪽 파란 말풍선 |
| 생각 중 | AI 말풍선 안 점 세 개 |
| 답 칸 | 둥근 입력 칸 + [보내기]. [바로 정리하기]는 작은 글자 버튼 |
| 방법별 그림 | 엘렌코스 물음표, 모르는 친구 웃는 얼굴, 오답 탐정 돋보기(SVG) |
| 오답 탐정 문장 | 흰 카드, 고르면 파란 테두리 |
| 결과 | 흰 카드에 왼쪽 색 띠(표시마다 초록·파랑·주황), 도움말·기록은 접는 상자 그대로 |
| 버튼 | 평평한 둥근 버튼(아래 그림자 없음) |
| 위 막대 | 버튼 글자 꺾이지 않게, 단원·교과서 표시는 길면 줄임표 |

## 지키는 것
- 교실 TV에서 함께 보는 큰 글씨(기본 32px)와 높은 대비.
- 빨간색·X·점수 없음.
- 문답 흐름, AI 규칙, 결과 글, 인쇄(A4 한 장)는 그대로. 화면 모양만 바뀝니다.
- 테스트가 쓰는 이름(`#answer`, `.qcard .q`, `.thinking`, `.reaction`, `.history`, `.error-box`, 버튼 글자)은 그대로 둡니다.

## 접근 방법
- 다른 길: (가) CSS만 바꾸기 — 말풍선 대화를 만들 수 없어 뺌. (나) 화면을 새로 짜기 — 세 방법을 다시 써야 해 위험이 큼.
- 고른 길: 공통 부품(`core/parts.js`)에 말풍선 대화 부품(`thread`)을 더하고 질문·생각 중 카드를 말풍선 모양으로 바꿉니다. 세 방법 화면은 기록 줄 대신 `thread`를 부르게만 고칩니다. 나머지는 `core/style.css`에서 바꿉니다.

## 확인
- `node --test "tests/*.test.js"` 모두 통과.
- 엘렌코스 화면 비교 기준(`tests/fixtures/elenchus-views-baseline.js`)은 의도한 모양 변화라 새로 찍고, 옛 기준 보정(`ADJUST`)은 지웁니다.
- 세 방법의 모든 장면을 1280px와 좁은 화면(375px)에서 눈으로 확인.
