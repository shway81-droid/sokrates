## 3. 오답 탐정이 하는 일

### 화면 흐름
1. 시작 안내: "친구의 정리에서 이상한 곳을 찾아볼까요?" + [시작]
2. 문제 화면: "친구가 배운 것을 이렇게 정리했어요. 한 곳이 이상해요." + 문장 카드 ①~④ + 진행 점
3. 어느 카드를 눌러도 똑같이 "이 문장이 왜 이상한가요?"와 까닭 칸이 나옵니다(보내기 전에는 맞는 문장인지 알려 주지 않음).
4. 보낸 뒤
   - **맞는 문장**: AI 없이 고정 문구 "생각을 말해 줘서 고마워요. 다른 문장도 다시 읽어 볼까요?" 그 카드는 흐리게. 두 번째면 "이 문제는 선생님과 함께 알아봐요." → **함께 더 알아봐요**(호박색)
   - **숨은 문장**: AI 판단. 핵심에 닿으면 **까닭까지 밝혔어요**(초록). 아니면 이어 묻는 질문(최대 2번) 뒤 마지막 판단 → 밝혔어요 또는 **이상한 곳을 찾았어요**(청록). 이어 묻는 질문에 "모르겠어요", "몰라요", "잘 모르겠어요", "글쎄요", "기억이 안 나요"처럼 **모른다는 말만** 하면 AI를 부르지 않고 바로 "이상한 곳을 찾았어요. 까닭은 선생님과 함께 더 알아봐요."로 마무리합니다(사용자님 요청, `isDontKnow`). "잘 모르겠지만 군인이요"처럼 내용이 있으면 전처럼 AI가 판단합니다. 처음 까닭 칸에 쓴 "몰라요"는 여기에 들지 않고 AI가 쉬운 질문을 한 번 냅니다
5. [다음 문제] → 2문제 뒤 결과 화면: 문제마다 표시와 4문장(찾은 문제만 숨은 문장 표시), 나의 까닭, 접힌 "선생님 도움말"(오개념·차시·쪽, 학생이 이상하다고 본 맞는 문장과 그 까닭), 기록, [복사][인쇄][다음 학생]
- 빨간색·X·점수 없음. AI 마무리 글 없음(고정 문구만).

### 코드가 정하고 AI는 JSON만
- 응답 형식(`schemaFor`): `judge`(solved/ask + question), `final`(solved/found), `question`(ask만 — 질문이 검사에 걸렸을 때 다시 받는 좁은 형식)
- 검사(`validateDetectiveStep`): 허용된 판단인지, `SokGuard.checkQuestion`(40자·"요?"·한 문장·금지어), 고르기 질문(`isChoice`), 앞 질문 되풀이, **정답 낱말(`leakIn`)** — 그 문제의 `leakWords` 가운데 학생이 아직 말하지 않은 낱말이 질문에 있으면 걸림(띄어쓰기 무시)
- 걸리면 까닭을 알려 주고 다시 받음(judge 2번, final 3번). 끝내 걸리면 기본 질문("그 부분이 실제로는 어땠는지 말해 줄래요?" 등)으로 대신하고 `fallbacks`에 셈
- **가정 검사**: 위를 모두 통과한 질문에 "~다면/~라면/~려면" 가정이 있으면 AI에게 한 번 더 묻습니다(`PREMISE_SYSTEM`, 응답 `{premise, side}`). 검사 AI는 가정이 그리는 상황을 `premise`에 먼저 적고, 그 상황이 누구 쪽인지 `side`로 냅니다 — `friend`(친구의 숨은 문장 쪽, "그대로/정말" 같은 말이 붙어도), `truth`(학생이 아직 말하지 않은 바른 생각을 담음), `other`(어느 쪽도 아님). `truth`면 다시 받고, 답이 형식에 맞지 않거나 검사 호출이 실패해도 그 질문은 쓰지 않습니다. 가정 질문일 때만 호출이 1번 늘어납니다(1~2초).
- 맞는 문장을 누른 기록은 AI에 보내지 않음(판단에 필요 없고, 학생이 헷갈린 것은 도움말로 선생님께만)
- 캐시: system=[프롬프트, 원문(cache_control)], user=[단원 맥락(cache_control), 이 문제와 학생 글]

### 문제 고르기 (`pickProblems`)
- 후보 = 그 교과서가 든 문제 + 오늘까지 배운 범위
- 첫 문제 = 오늘 차시 오개념(없으면 앞 차시), 둘째 = 오늘의 다른 오개념(없으면 앞 차시 전체, 화면에 "앞에서 배운 내용 복습"). 단원 마무리는 전체에서 두 개. **2026-11-25 바꿈**: 전에는 둘째가 앞 차시라 6·25 전쟁 차시에 임시 정부 문제가 나와 사용자님이 "둘 다 오늘 차시로" 정하심
- 차례: 안 낸 문제 → 안 낸 문제지만 오개념은 나옴 → 낸 문제. 다 냈으면 그 무리를 비우고 다시 돎
- **둘째 문제는 첫 문제의 4문장에 자기 정답 낱말이 보이는 것을 피함**(`a7e665e`). 같은 차시 문제끼리 맞는 문장이 서로의 정답을 말하는 경우가 데이터에 430쌍 있었음. 모든 교과서·차시 1120번 모의로 0쌍
- **두 문제가 서로의 답을 보이지 않게 고름**(사용자님 요청으로 보탬): 위와 거꾸로, 둘째 문제의 문장에 첫 문제의 정답 낱말이 있는 것도 피함(첫 문제를 못 찾고 끝나면 결과 화면에서 답이 보이기 때문). 고르는 차례는 앞 차시의 깨끗한 문제 → 오늘 차시의 깨끗한 문제 → (그래도 없으면) 앞 차시 → 오늘 차시. 전에는 앞 차시에 깨끗한 문제가 없으면 오늘 차시를 보지 않고 앞 차시에서 그냥 골라, 3-10차시(천재·비상)에서 첫 문제 문장에 둘째 문제의 정답 낱말 '독립운동'이 보이는 일이 있었음. 실제 데이터로 270번 모의: 고치기 전 정방향 4·거꾸로 15 → 고친 뒤 0·0.
  - **2026-11-25 다시 정함**(둘 다 오늘 차시로 바꾸며): 오늘 차시 → 앞 차시 순서가 먼저이고, 같은 무리 안에서 겹침을 봅니다. 겹침 정도 0(없음)·1(둘째 카드에 첫 문제 답, 결과 화면에서만 보임)·2(첫 문제 카드에 둘째 답, 풀기 전에 보임). 2는 다른 문제가 있으면 내지 않고, 첫 문제는 2가 아닌 짝이 있는 문제로 먼저 고릅니다. 1은 돌림 차례가 같을 때만 뒤로 미룹니다(1까지 빼면 3-10차시 m11 두 문제·m15.b가 한 번도 안 나옴). 실제 데이터 모의(차시마다 40명): 오늘 차시 둘 = 오개념이 둘 이상인 모든 차시 40/40, 복습은 (그때) 오늘 오개념이 하나뿐인 천재 3·8~9차시, 비상 5·8차시 — 아래 오개념 4개를 더한 뒤 0, 2는 0번, 1은 3-10에서 13/40 정도, 모든 문제가 한 번 이상 나옴.

## 8. 예시 학생 (화면에서 해 보기)

앱(`http://localhost:8773`)에서 단원 3을 고르고 아래 교과서·차시를 고릅니다. 문제는 고르기 규칙에 따라 몇 가지 가운데 하나가 나오므로, 나온 숨은 문장에 맞춰 까닭을 씁니다.

| 학생 | 교과서·차시 | 하는 것 | 기대 표시 |
|---|---|---|---|
| 1. 낮은 수준(맞춤법·짧은 말) | 천재 4차시 | 숨은 문장을 누르고 맞춤법 틀린 짧은 까닭: 농촌에서 시작 → "서울에서 먼저햇어요" / 임시 정부가 이끔 → "임시정부는 나중에 생겻어요" / 둘째(의병 약해짐) → "군인들이 들어가서 더 쎄졋어요" / 둘째(1910년대 국내 활동) → "감시가 심해서 외국으로 갓어요" | 까닭까지 밝혔어요 ×2 |
| 2. "몰라요" | 비상 3~4차시 | 첫 문제: 숨은 문장을 누르고 까닭·질문 두 번 모두 "몰라요" / 둘째: 맞는 문장을 두 번 누르고 "몰라요" | 이상한 곳을 찾았어요 / 함께 더 알아봐요 |
| 3. 부정만 하다 답함 | 천재 4차시 | 숨은 문장에 "아니에요" → 질문을 읽고 바른 까닭(예: "3·1 운동은 서울에서 시작했어요") | 까닭까지 밝혔어요 |
| 4. 맞는 문장 먼저 | 비상 3~4차시 | 맞는 문장 하나를 누르고 "이상해요" → 안내 문구 확인 → 숨은 문장을 누르고 바른 까닭(쌀 → "일본이 쌀을 가져가서 더 어려워졌어요" / 학교 → "학교에서 일본어로 수업했어요") | 까닭까지 밝혔어요 |
| 5. 장난·고집 | 천재 4차시 | 숨은 문장에 "ㅋㅋ 몰라" → 질문에 "그 문장이 맞는 것 같아요" → "그냥요" | 이상한 곳을 찾았어요 |

## 9. 다음 방법을 만드는 세션에게
