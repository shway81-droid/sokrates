## 3. 오답 탐정이 하는 일

### 화면 흐름
1. 시작 안내: "친구의 정리에서 이상한 곳을 찾아볼까요?" + [시작]
2. 문제 화면: "친구가 배운 것을 이렇게 정리했어요. 한 곳이 이상해요." + 문장 카드 ①~④ + 진행 점
3. 어느 카드를 눌러도 똑같이 "이 문장이 왜 이상한가요?"와 까닭 칸이 나옵니다(보내기 전에는 맞는 문장인지 알려 주지 않음).
4. 보낸 뒤
   - **맞는 문장**: AI 없이 고정 문구 "생각을 말해 줘서 고마워요. 다른 문장도 다시 읽어 볼까요?" 그 카드는 흐리게. 두 번째면 "이 문제는 선생님과 함께 알아봐요." → **함께 더 알아봐요**(호박색)
   - **숨은 문장**: AI 판단. 핵심에 닿으면 **까닭까지 밝혔어요**(초록). 아니면 이어 묻는 질문(최대 2번) 뒤 마지막 판단 → 밝혔어요 또는 **이상한 곳을 찾았어요**(청록)
5. [다음 문제] → 2문제 뒤 결과 화면: 문제마다 표시와 4문장(찾은 문제만 숨은 문장 표시), 나의 까닭, 접힌 "선생님 도움말"(오개념·차시·쪽, 학생이 이상하다고 본 맞는 문장과 그 까닭), 기록, [복사][인쇄][다음 학생]
- 빨간색·X·점수 없음. AI 마무리 글 없음(고정 문구만).

### 코드가 정하고 AI는 JSON만
- 응답 형식(`schemaFor`): `judge`(solved/ask + question), `final`(solved/found), `question`(ask만 — 질문이 검사에 걸렸을 때 다시 받는 좁은 형식)
- 검사(`validateDetectiveStep`): 허용된 판단인지, `SokGuard.checkQuestion`(40자·"요?"·한 문장·금지어), 고르기 질문(`isChoice`), 앞 질문 되풀이, **정답 낱말(`leakIn`)** — 그 문제의 `leakWords` 가운데 학생이 아직 말하지 않은 낱말이 질문에 있으면 걸림(띄어쓰기 무시)
- 걸리면 까닭을 알려 주고 다시 받음(judge 2번, final 3번). 끝내 걸리면 기본 질문("그 부분이 실제로는 어땠는지 말해 줄래요?" 등)으로 대신하고 `fallbacks`에 셈
- 맞는 문장을 누른 기록은 AI에 보내지 않음(판단에 필요 없고, 학생이 헷갈린 것은 도움말로 선생님께만)
- 캐시: system=[프롬프트, 원문(cache_control)], user=[단원 맥락(cache_control), 이 문제와 학생 글]

### 문제 고르기 (`pickProblems`)
- 후보 = 그 교과서가 든 문제 + 오늘까지 배운 범위
- 첫 문제 = 오늘 차시 오개념(없으면 앞 차시), 둘째 = 앞 차시 전체(없으면 오늘의 다른 오개념). 단원 마무리는 전체에서 두 개
- 차례: 안 낸 문제 → 안 낸 문제지만 오개념은 나옴 → 낸 문제. 다 냈으면 그 무리를 비우고 다시 돎
- **둘째 문제는 첫 문제의 4문장에 자기 정답 낱말이 보이는 것을 피함**(`a7e665e`). 같은 차시 문제끼리 맞는 문장이 서로의 정답을 말하는 경우가 데이터에 430쌍 있었음. 모든 교과서·차시 1120번 모의로 0쌍
- 낸 문제 기억(`SERVED`)은 브라우저 탭 메모리입니다. 새로 고치면 처음부터 돕니다(학생 기록은 저장하지 않는다는 원칙과 같음)

## 4. 데이터와 공정

- 모양: `{ id: "3-2.m06.a", misconception, textbooks, sentences[4], hidden, key, hints[2], leakWords[], reviewed }`
- 공정: 초안 에이전트(근거 메모를 스크래치에 남김) → **새 맥락 검증 에이전트**가 교과서 원문(`work/3/`)과 한 문제씩 대조해 직접 고침 → `reviewed: true`
- 검증에서 고친 것(요지)
  - 퀴즈 꼴 hints("어떤 모임일까요?", "어떤 곳일까요?") → 학생 주장의 결과를 묻는 질문
  - 정답을 품은 hints("…중국군이 들어오자 어떻게…") → 정답 없는 질문
  - 근거가 한 교과서에만 있는 맞는 문장 → 세 교과서 본문에 다 있는 문장
  - 맞는 문장이 같은 차시 다른 오개념의 바른 생각을 말하는 것(3-1에서 여러 개) → 다른 사실로
  - 시간 순서가 어긋난 배치(3-1.m01.a), "이때/이 사업"처럼 숨은 문장을 가리키는 말
  - 빠진 정답 낱말 더하기
- 데이터 테스트(`detective-data.test.js`): 오개념마다 2개, textbooks ⊂ sources, 4문장·40자·"요.", 숨은 위치 고루(각 8개 이상), key·hints 규칙, leakWords가 문장·hints에 없음, 모두 reviewed, 원문 25자 이상 같은 곳 없음
- 3-1.m02(비상만), m04(아이스크림만), m05(천재만)는 오개념 자체가 한 교과서에만 있어 그 교과서에서만 나옵니다.

## 6. 해 보며 배운 것

- **데이터를 미리 만들고 새 맥락이 원문 대조**하는 것이 컸습니다. 초안에서 퀴즈 꼴 힌트, 정답을 품은 힌트, 한 교과서에만 있는 문장, 다른 오개념의 정답을 말하는 맞는 문장이 많이 나왔고, 검증자가 거의 다 잡았습니다.
- 다만 검증자도 "**같은 세션에 함께 나올 다른 문제**"와의 겹침은 따로 시키지 않으면 놓칩니다(3-2 검증자는 안 봄, 3-1은 시켜서 봄). 스크립트로 한 번 보는 것이 빠릅니다.
- 하이쿠는 학생이 "몰라요/아니에요"만 하면 **사실을 묻는 질문**(무엇·언제·어떤 일)으로 기웁니다. 프롬프트에 금지 예를 넣어도 나옵니다. 코드 검사가 필요합니다.
- 기본값 대체가 일어나도 어떤 검사에 걸렸는지 점검 페이지에 남지 않아 원인을 볼 수 없었습니다.
- 브라우저 캐시: `?v=` 고정 줄을 고칠 수 없는 규칙이면 새 스타일이 안 보일 수 있습니다(2장).

## 7. 남은 문제 (보완 후보 — 고칠지는 사용자님이 정하십니다)

1. **사실을 묻는 퀴즈 꼴 질문이 검사를 통과함** — "무엇을 뽑았을까요?", "언제였을까요?", "어떤 일을 한 사람이었을까요?" (점검 3·5·12·16번). 보완 안: 검사에 사실 묻기 꼴(언제·누구·무엇을·어디에서·어떤 일을 한) 정규식을 더해 걸리면 다시 받기.
2. **정답 원인을 먼저 꺼내는 질문** — "휴전선이 생긴 뒤에도 가족들이 쉽게 만날 수 있었을까요?"(6번). 보완 안: `3-2.m08` leakWords에 "휴전선" 더하기(맞는 문장에 '휴전선'이 없는지 확인 필요). 다른 문제도 key의 원인 낱말이 leakWords에 있는지 한 번 훑기.
3. **질문이 "그럼"으로 자주 시작**(6/11) — 프롬프트에 "그럼으로 시작하지 않기" 한 줄.
4. **"몰라요"만 하는 학생의 둘째 질문이 늘 같음**("그 문장에서 어느 낱말이 가장 이상해 보였나요?" — 프롬프트 예시를 그대로 씀). 예시를 둘 이상으로.
5. **이어 묻는 중에 [바로 정리하기]를 누르면 AI 마지막 판단 없이 "이상한 곳을 찾았어요"**가 됩니다. 학생이 이미 앞 답에서 핵심을 말했어도 그렇습니다(이 경우 질문이 나오지 않았을 것이라 드물지만). 그대로 둘지 정하시면 됩니다.
6. 점검 페이지가 기본값 대체의 원인(걸린 검사)을 남기지 않음.
7. style.css `?v=` 올리기(합치는 세션, 2장).

## 8. 예시 학생 (화면에서 해 보기)

앱(`http://localhost:8773`)에서 단원 3을 고르고 아래 교과서·차시를 고릅니다. 문제는 고르기 규칙에 따라 몇 가지 가운데 하나가 나오므로, 나온 숨은 문장에 맞춰 까닭을 씁니다.

| 학생 | 교과서·차시 | 하는 것 | 기대 표시 |
|---|---|---|---|
| 1. 낮은 수준(맞춤법·짧은 말) | 천재 4차시 | 숨은 문장을 누르고 맞춤법 틀린 짧은 까닭: 농촌에서 시작 → "서울에서 먼저햇어요" / 임시 정부가 이끔 → "임시정부는 나중에 생겻어요" / 둘째(의병 약해짐) → "군인들이 들어가서 더 쎄졋어요" / 둘째(1910년대 국내 활동) → "감시가 심해서 외국으로 갓어요" | 까닭까지 밝혔어요 ×2 |
| 2. "몰라요" | 비상 3~4차시 | 첫 문제: 숨은 문장을 누르고 까닭·질문 두 번 모두 "몰라요" / 둘째: 맞는 문장을 두 번 누르고 "몰라요" | 이상한 곳을 찾았어요 / 함께 더 알아봐요 |
| 3. 부정만 하다 답함 | 천재 4차시 | 숨은 문장에 "아니에요" → 질문을 읽고 바른 까닭(예: "3·1 운동은 서울에서 시작했어요") | 까닭까지 밝혔어요 |
| 4. 맞는 문장 먼저 | 비상 3~4차시 | 맞는 문장 하나를 누르고 "이상해요" → 안내 문구 확인 → 숨은 문장을 누르고 바른 까닭(쌀 → "일본이 쌀을 가져가서 더 어려워졌어요" / 학교 → "학교에서 일본어로 수업했어요") | 까닭까지 밝혔어요 |

## 9. 다음 방법을 만드는 세션에게
